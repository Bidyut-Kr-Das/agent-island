Agent Islands · phone link

Six ways to reach the island from your phone

Every option keeps the same PC side: Claude Code sends hook events to the island over the named pipe that exists today. What changes is the middle and what you see on the phone. The orange box in each diagram is where you look.

01 · Own pipe · recommended

Tailscale + island web app

You see
A web page that the island itself serves. Open it once in Safari or Chrome and add it to your home screen, and it looks like an app. The Tailscale app only keeps the private network up. It has no screen for this.
Needs
Tailscale on PC and phone, signed in to the same account. A small HTTP + WebSocket server inside agent-islands.exe, plus web push keys.
Catch
iPhone shows web push only for pages added to the home screen (iOS 16.4+). The phone page works only while Tailscale is connected.

02 · Fastest to build

Telegram bot

You see
A chat with your own bot in the Telegram app. Each update is a message. Permission prompts come with Allow and Deny buttons. Reply to a message to send an instruction.
Needs
A bot token from BotFather. The island polls Telegram over HTTPS. No open port, no server of your own.
Catch
Telegram stores every message. The bot must ignore every chat ID except yours.

03 · Own pipe · home only

Home Wi-Fi web page

You see
A browser tab at the PC's local address. It updates only while the tab is open.
Needs
A small HTTP + WebSocket server inside the island, a Windows firewall rule, and a login token.
Catch
Works on home Wi-Fi only. Plain HTTP, so no push notifications. Anyone on the Wi-Fi can reach the port.

04 · Own pipe · most work

Own cloud relay

You see
A web app on your own domain, served by the relay. It works the same as the Tailscale page, but you need no VPN app on the phone.
Needs
A server you host, a domain, login with sessions, and ideally end-to-end encryption so the relay cannot read your prompts.
Catch
You own uptime, TLS, and security. The URL is public, so a weak login lets a stranger approve rm on your PC.

05 · Not recommended

Public tunnel

You see
The same island web page as option 03, but at a public HTTPS address. Push notifications are possible here too.
Needs
The island's HTTP server, the cloudflared or ngrok agent running on the PC, and strong login.
Catch
The whole internet can reach a page that approves commands on your PC. The only thing in the way is your login.

06 · Simple · buttons only

ntfy push

You see
Notifications in the ntfy app. Permission prompts get Allow and Deny buttons that post back to a second topic, which the island listens on.
Needs
The ntfy app, plus random topic names and an access token (or a self-hosted server).
Catch
No easy way to type a free-text instruction. It suits updates and Allow/Deny, not a conversation.
